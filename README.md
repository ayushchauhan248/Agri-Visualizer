# Indian Agriculture Data Visualization

This project visualizes Indian agriculture data using Mantine and Apache ECharts. The app features a table that shows the crops with the maximum and minimum production per year and a bar chart displaying the average crop production for each crop.

## Technologies Used
- **TypeScript** for type safety and better code maintainability.
- **Vite** as the build tool.
- **Mantine** for UI components such as the table and buttons.
- **Apache ECharts** for rendering the bar chart.
- **React** for building the user interface.
- **Yarn** as the package manager.

## Features
1. **Data Table**: Displays the crop with maximum and minimum production for each year.
2. **Bar Chart**: Shows the average production of each crop across all years.
4. **No External Libraries**: No external UI libraries like Bootstrap, jQuery, or Lodash are used.

## Setup Instructions

### Prerequisites

Make sure you have the following installed on your machine:

- **Node.js** (version 18.x or higher)
- **Yarn** (to install dependencies)

### Getting Started

1. Clone the repository to your local machine:

   git clone https://github.com/ayushchauhan248/Agri-Visualizer.git

   cd Agri-Visualizer

2. Install the project dependencies:

   yarn install

3. Run dev server:

   yarn dev
